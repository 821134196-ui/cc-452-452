# 物流园挂车甩挂与车钥匙交接平台

牵引车甩挂作业的园区调度系统：管理牵引车、挂车、司机、停车位、到离园预约、
挂接关系、铅封号、车钥匙、外观检查、等待时长与交接责任人。所有车牌、司机
均为**虚构样例数据**。

## 一条命令启动

```bash
./run.sh              # 首次自动加载高峰样例，随后启动服务
# 浏览器打开 http://localhost:8000
```

需要重建样例：`./run.sh --reseed`。仅 Python 3.10+ 标准库，**零第三方依赖**，
无需安装任何包。默认演示时钟固定在 `2026-09-30 08:30:00`（高峰时刻）；
需要跟随系统时钟可加 `--fixed-time ""`。

岗位工号（免密演示登录）：

| 工号 | 岗位 | 可执行操作 |
|---|---|---|
| `gate01` | 门岗 | 车辆签到放行、出园核验放行 |
| `disp01` / `disp02` | 调度员（双人） | 分配车位、解绑、轮挡、发起提挂、挂接、无法提挂 |
| `key01` | 钥匙员 | 钥匙入柜、取钥发放 |
| `insp01` | 查验员 | 铅封核对、外观检查 |
| `sup01` | 值班主管 | 异常放行审批 |

## 作业流程

```
到园签到 ──► 待卸挂队列 ──► 分配车位（挂车停妥）
                              ├─ 解绑登记（调度）
                              ├─ 轮挡确认（调度）
                              └─ 钥匙入柜（钥匙员）──► 交接完成
提挂：核对司机 → 铅封 → 外观（查验）→ 挂接（调度）→ 取钥（钥匙员）
出园：核验清单 → 异常车须主管批准 → 道闸抬起 → 关闭本次周转
```

**交接完成四要件缺一不可**：停妥入位、解绑登记、轮挡确认、钥匙入柜。

## 看板

- **车辆到园**：预约/实际到园、迟到标记、签到抬杆（模拟门岗适配器）
- **甩挂队列**：等待时长进度条、≥30 分钟超时（后台线程扫描）、四步交接
- **车位图**：A/B/C 三区按真实编号（区-排-列）平面行列排布，空/占/锁定三态
- **挂接操作**：牵引车（蓝轮廓）与挂车（黄轮廓）符号区分，提挂核验五步
- **钥匙柜台账**：每把钥匙一张**可扫描密集条码清单**，格口占用与错格告警
- **外观对照**：到园/提挂两组照片，围绕车辆平面轮廓的前/左/右/尾四方位展开
- **出园核验**：五项核验清单 + 异常审批状态，异常车红色"异常放行"按钮
- **异常流水**：迟到、车位占用、钥匙错格、铅封不符、损伤、司机替换、
  无法提挂、等待超时等单独事件留痕

界面配色：沥青灰底、车道白分隔线、信号黄主操作色。外观照片为本地 SVG 模拟图
（"外观对照"页可按方位补拍），存于 `data/photos/`。

## 关键业务规则

- **挂接唯一性**：`hitches` 表对 `active=1` 的挂车建部分唯一索引，
  一辆挂车同一时刻只允许一组有效挂接（到园挂入、解绑释放、提挂重新挂入）。
- **车位竞争**：分配使用单条条件 `UPDATE ... WHERE status='free'`，
  两个调度员并发抢占时由 SQLite 原子裁决，**仅首个成功**，第二个收到
  `slot_taken` 并写入"车位被占"预警事件。
- **异常放行**：铅封不符/外观损伤/无法提挂 → 车辆挂起；一线岗位发起申请，
  **仅值班主管可批准**；批准后业务步骤（铅封/外观/挂接/取钥）仍须完成，
  出园时再次校验批准记录，全程关键事件留痕。
- **钥匙错格**：存入已被占用格口或从与登记不符的格口取钥均触发错格告警，
  错格不构成交接完成。
- **角色权限**：RBAC 矩阵在服务端强校验（见 `platform/permissions.py`），
  前端按钮仅按角色显隐，越权调用 API 返回 403。

## 技术结构

```
platform/
  db.py           SQLite schema（挂接部分唯一索引等约束）+ 数据访问
  clock.py        可注入时钟（演示/测试）
  permissions.py  角色权限矩阵
  adapters.py     门岗道闸 / 智能钥匙柜模拟适配器
  service.py      业务状态机、事务、等待超时后台线程
  server.py       零依赖 http.server：JSON API + 静态页 + 照片目录
  seed.py         高峰样例 + SVG 外观照片生成
  web/            index.html / styles.css / app.js（原生 JS）
data/             yard.db（SQLite）+ photos/（本地外观照片）
tests/            29 个 unittest 用例
```

## 运行测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：挂接唯一性（索引级 + 业务级）、两调度员并发车位竞争、交接四步骤与
顺序约束、铅封不符/损伤的异常审批放行链路、主管权限边界、门岗故障、
迟到/替换/错格/无法提挂/等待超时事件、适配器结果。

## 常用开发接口

- `GET /api/arrivals|queue|slots|hitches|keys|exits|events|turns/<id>`
- `POST /api/actions/{arrive,assign-slot,unhitch,chock,deposit-key,
  start-pickup,verify-seal,inspect,cannot-pickup,hitch,release-key,
  request-approval,decide-approval,exit}`
- `POST /api/mock/photo` 按方位生成一张 SVG 外观照片
- `POST /api/dev/advance {"minutes": n}` 推进演示时钟并立即扫描超时
