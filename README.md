# 物流园挂车甩挂与车钥匙交接平台

管理牵引车、挂车、司机、停车位、到离园预约、挂接关系、铅封号、车钥匙、
外观检查、等待时长与交接责任人的本地一体化平台。**车牌与司机资料均为虚构数据。**

仅使用 Python 标准库（`sqlite3` / `http.server` / `threading`），无需安装任何依赖。

## 一条本地启动命令

```bash
python3 run.py --reseed
```

启动后自动打开浏览器 <http://127.0.0.1:8000/> 并加载早高峰样例。
不加 `--reseed` 时保留已有数据继续运行；`--port` 可改端口，`--no-browser` 不弹浏览器。

运行测试：

```bash
python3 -m unittest tests.test_platform -v
```

## 交接业务流程

```
到园签到(门岗)            车辆识别抬杆、迟到判定
   ↓ 进入待卸挂队列        进程内任务计时等待超时
分配车位(调度员)          两个调度员抢占同一车位，条件 UPDATE 仅首个成功
   ↓
解除牵引/挂接(调度员)      依赖挂接唯一索引
   ↓
入位外观检查+铅封(查验员)  前/后/左/右/顶 五方位拍照存本地文件夹，损伤开异常单
   ↓
挂车停妥 → 轮挡确认 → 钥匙扫码入柜(钥匙员)   三步齐全才算甩挂交接完成；错格不完成
   ↓
安排提挂车/司机(调度员)    司机与预约不同 → 司机替换异常
   ↓
提挂三项核对(查验员)      司机 / 铅封号 / 外观对照（新增损伤拦截）
   ↓
取钥匙(钥匙员) → 挂接(调度员)   同一挂车同一时刻仅一组有效挂接；挂接释放车位
   ↓
出园核验(门岗)            正常出园关闭周转；异常车辆须值班主管批准
```

## 异常单（独立记录）

预约迟到、车位占用、钥匙错格、铅封不符、挂车损伤、司机替换、无法提挂、异常放行。
异常放行只能由**值班主管**批准/驳回；未批准车辆无法出园。

## 七个界面

1. **到园看板** —— 指标、阶段流水线、等待时长超时告警、未关闭异常、事件流
2. **甩挂队列 / 交接** —— 签到、待卸挂队列、分位（含「⚡模拟抢占」并发按钮）、交接步骤卡片
3. **车位图** —— A/B/C 三区按真实编号排成平面行列（区-行列，如 A-205），占用可点看外观
4. **挂接操作** —— 当前有效挂接关系、提挂核对/取钥匙/挂接
5. **钥匙柜台账** —— 3×8 智能钥匙柜格口图 + 可扫描条码的密集清单
6. **外观对照** —— 车辆轮廓方位图，五方位入位/提挂照片在对应方位旁展开，铅封记录
7. **出园核验** —— 三项核对状态、正常/异常出园、主管审批列表

界面配色：沥青灰底、车道白字、信号黄强调；牵引车（车头轮廓）与挂车（长厢轮廓）
使用不同 SVG 符号区分。

## 关键技术点

- **挂接唯一性**：`couplings` 上的部分唯一索引
  `WHERE deleted=0`，一个挂车（及一个牵引车）同一时刻只有一组有效挂接。
- **车位竞争**：`UPDATE stalls SET status='occupied' WHERE id=? AND status='free'`
  比较并设置，配合写操作串行锁；并发分位仅首个 `rowcount=1` 成功，败者开「车位占用」异常。
- **交接步骤**：`cycles.phase` 状态机严格顺序推进，错格/未轮挡等不会提前完成。
- **等待超时**：守护线程每 5 秒扫描 `wait_tracking`，超时写入事件并在看板告警，只提醒一次。
  阈值可用环境变量调整：`YP_QUEUE_TIMEOUT`、`YP_PICKUP_TIMEOUT`、`YP_TICK`。
- **模拟适配器**：`GateAdapter`（车牌识别/抬杆）、`KeyCabinetAdapter`（牌号→格口核对）、
  `PhotoStore`（把外观照片 SVG 写入 `data/photos/`）。
- **存储**：SQLite 位于 `data/yard.db`；外观照片位于 `data/photos/`。
